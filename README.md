This repository is also the reference implementation for how I want your own project repositories organized. The structure below is the structure I'll be looking for in your work.

## Setup
 
### 1. Install R and RStudio
 
- **R** (version 4.3 or later): https://cran.r-project.org/
- **RStudio Desktop** https://posit.co/download/rstudio-desktop/

### 2. Change two settings: 

Go to Global Options and set: 
- **Restore .RData into workspace at startup** — unchecked
- **Save workspace to .RData on exit** — Never
Do this before you write any code. A saved workspace means your script appears to work because of an object you created three weeks ago and forgot about. When you send that script to me, or to anyone, it breaks. Your code should run correctly in a fresh R session, every time.


## Repository structure
 
```
scripts/     in-class code and worked examples
data/        datasets used in class
output/      figures and tables produced by scripts/
```
